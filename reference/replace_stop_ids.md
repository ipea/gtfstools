# Replace stop_ids

Replace stop_ids

## Usage

``` r
replace_stop_ids(x, old_id, new_id)
```

## Arguments

- x:

  A character vector of `stop_id`s.

- old_id, new_id:

  Character vectors with the old and the new `stop_id` of each stop.

## Value

`x`, with the ids found in `old_id` replaced by their `new_id`.
