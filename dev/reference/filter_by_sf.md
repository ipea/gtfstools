# Filter a GTFS object using a `simple features` object (defunct)

This function was deprecated in gtfstools 1.3.0 and is now defunct:
calling it raises an error. Please use
[`filter_by_spatial_extent()`](https://ipea.github.io/gtfstools/dev/reference/filter_by_spatial_extent.md)
instead, which takes the same arguments.

## Usage

``` r
filter_by_sf(...)
```

## Arguments

- ...:

  Ignored.

## Value

Doesn't return: always raises an error.

## See also

[`filter_by_spatial_extent()`](https://ipea.github.io/gtfstools/dev/reference/filter_by_spatial_extent.md),
which replaces this function.
