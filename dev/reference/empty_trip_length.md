# Create an empty output of `get_trip_length()`

Create an empty output of
[`get_trip_length()`](https://ipea.github.io/gtfstools/dev/reference/get_trip_length.md)

## Usage

``` r
empty_trip_length(by)
```

## Arguments

- by:

  Either `"trip"` or `"segment"`.

## Value

An empty `data.table` with the columns of the output of
[`get_trip_length()`](https://ipea.github.io/gtfstools/dev/reference/get_trip_length.md).
